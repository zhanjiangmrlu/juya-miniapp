## 真实联调与外部验收

真实脚本必须从页面触发动作并捕获HTTP，检查场景实际ID/修订、收藏不同快照、完整翻卡、资料POST后GET回读、录音关闭时完成、纯短文本轮完成POST后刷新回读。已完成短文必须换新资料，缺必需实体不能标通过。

私有合法新会话的所有API非2xx、requestfailed及页面异常均阻断，当前没有默许的路径/状态例外。HTTP仅记录方法、路径、状态、request_id、顶层字段名及固定错误分类；不保存令牌、正文、签名URL、HAR或storageState，截图遮挡本人资料。

脚本就绪不等于已执行。真实服务由协调统一启动和提供隔离会话，完成后以 browser-results.json 回填。微信静默登录、真机昵称/头像/麦克风授权、iOS/安卓/平板播放录音、OSS Range/短签名、版权/真人试听与生产发布分别待验收。
