# 友盟测试与生产环境统计

微信小程序按构建模式接入独立应用：`--mode test` 使用 `juya-miniapp-test`，`--mode production` 使用 `juya-miniapp-prod`。development、本地分享和 H5 保持关闭。两种模式都使用现有32个事件，不根据微信开发版/体验版/正式版的envVersion切换统计账号。

## 私有配置

两套AppKey均从工作区指定账号资料文件读取，只放入被Git忽略、权限0600的私有环境文件：

- `.env.test.local`：`VITE_UMENG_ENABLED=true`、`VITE_UMENG_TEST_APP_KEY=<测试应用AppKey>`
- `.env.production.local`：`VITE_UMENG_ENABLED=true`、`VITE_UMENG_PROD_APP_KEY=<生产应用AppKey>`

版本化环境文件只提供变量名，不包含真实值。每种模式只读取对应AppKey，缺失时关闭，不向另一套环境回退。H5及开发模式即使携带两套配置仍关闭。事件environment维度分别为test/production。

测试与生产的协议同意保存在不同存储键，生产不沿用测试同意；SDK访客标识、队列和缓存也分别使用juya-umeng-test:/juya-umeng-prod:命名空间。业务全局wx及其存储不受影响。授权前不读取SDK存储、不初始化、不发送；仍由登录页主动协议勾选决定。

微信公众平台需将 `https://umini.shujupie.com` 加入 request 合法域名。正式数据接收仍须在对应测试/生产小程序真机与友盟应用分别核对，模拟 SDK 微信端口的测试不代表服务端已接收数据。

## 用户选择

友盟用途、设备/网络/访问及学习操作信息、随机访客标识、第三方信息处理规则链接，集中在已有《隐私说明》面板。按用户最新要求，登录页的原隐私协议勾选与统计联动：主动勾选时保存并开启统计，取消勾选时撤回并关闭；不新增复选框或弹窗。登录页同时显示联动提示。

按用户最新要求，移除隐私说明中的“允许使用统计”开关及其文案、处理函数和样式，面板只解释用途与数据范围，不提供另一个统计控件。仅打开或关闭说明面板不改变已保存的统计选择。统计开启/关闭由登录页的协议勾选事件驱动。

当前方案没有已登录用户专用的独立撤回入口，不能将其视为已满足便捷撤回同意或保证通过审核；绑定非必要统计与登录同意也有合规风险。此项在本轮已向用户说明，当前测试与生产接入均沿用用户指定的授权方式。

登录页及账号页已有隐私说明入口，游客亦可查看，统计选择由登录页协议勾选驱动。仅打开/关闭隐私说明、恢复已有业务会话不自动取得新的统计同意。首次协议勾选默认未选中，不因已保存的统计选择预选登录协议；既有统计选择按原规则恢复。用户主动勾选或开启后，保存版本为 2026-11-09 的本地选择，从当前页面开始；不补传开启前的访问。关闭后结束当前已授权会话，阻止新采集，并取消 SDK 作用域内在途网络任务。此前已发送的数据不会因关闭开关自动删除。

## 事件及口径

| 事件 ID           | 含义                                                               |
| ----------------- | ------------------------------------------------------------------ |
| app_entry         | 已授权的前台访问                                                   |
| page_enter        | 进入或返回页面，包含 Tab 切换与从后台返回                          |
| page_stay         | 离开页面、进入后台或撤回授权时结算本次前台停留，duration_ms 为毫秒 |
| login_prompt      | 实际弹出业务登录提示                                               |
| login_success     | 主动登录成功；恢复会话不计登录                                     |
| learning_start    | 已登录用户正常进入学习正文；只读恢复不计新开始                     |
| learning_complete | 服务端确认完成，包括原操作回执恢复                                 |
| favorite_change   | 服务端确认收藏/取消收藏                                            |
| share_trigger     | 原生分享回调触发，不表示分享成功或被接收                           |
| audio_play        | 全文播放或单词点读操作，表示播放意图，不等于实际出声成功           |
| audio_pause       | 页面主动暂停，或前台系统音频面板/耳机暂停、停止                    |
| audio_seek        | 主动拖动全文位置，记录约束后的目标秒数                             |
| audio_rate_change | 主动选择有效倍速，记录目标倍率，不表示设备一定应用成功             |
| audio_ended       | 原生音轨播放结束；不自动算学习完成                                 |
| audio_error       | 全文准备/原生播放失败，或单词重试后最终失败，不传原始报错文本      |

| 事件 ID            | 记录时机                     |
| ------------------ | ---------------------------- |
| entry_click        | 点击主要业务入口时           |
| content_click      | 点击场景或听读内容时         |
| tab_change         | 主动切换业务标签时           |
| category_select    | 主动切换听读分类时           |
| translation_toggle | 主动展开或收起译文时         |
| dictionary_lookup  | 主动查词或重试查词时         |
| dictionary_success | 当前查词结果获取成功时       |
| image_open         | 主动查看内容原图时           |
| study_note_open    | 主动打开学习笔记时           |
| study_note_ready   | 笔记下载校验完成、准备打开时 |
| content_next       | 主动前往下一张或下一篇时     |
| checkin_expand     | 展开某日打卡明细时           |
| feedback_submit    | 服务端确认新反馈提交成功时   |
| feedback_reply     | 服务端确认补充反馈成功时     |
| profile_save       | 服务端确认头像昵称保存成功时 |
| logout             | 主动退出登录成功时           |
| business_error     | 关键业务执行异常或被拦截时   |

按用户最新要求，移除 content_view，不采集内容、列表条目或元素曝光。page_enter 和 page_stay 使用不含 query 的 page_path，内容详情及原图页面补充 content_type/content_id。页面路径覆盖 pages.json 全部 18 个页面；SDK 的 Page 与 Component 两种注册方式均有生命周期回归。

同一可见区间内重复 onShow 不多算进入；onHide/onUnload 重复只结算一次。切页后保留离开页的上下文，不将其停留记到新页面。停留从获得授权且 SDK 就绪时开始，授权前、初始化等待和后台时长不计入；回到前台另起一段。进程被系统直接终止且没有隐藏/卸载回调时，最后一段无法保证结算，不作持久补传。

音频维度包括 content_type/content_id、version_id、audio_kind（full/word）。全文操作补充 position_s、audio_duration_s、playback_rate；单词补充 word_id（预置词条编号，或正文 line_id:start:end）。content/version 不在正文 word_id 内重复，避免 UUID 组合超过 128 字符。trigger 区分 control（页面主动操作）、system（系统续播/暂停）、native（播放结束/失败）。恢复进度、恢复快照的倍速/位置、切速内部暂停、全文与词音轨互斥暂停不记成主动点击。不按 onTimeUpdate 高频上报；后台音频事件沿用前台采集边界，不记录或补传。

事件仅包含页面路径、停留毫秒数、内容类型/ID/版本、非正文词汇引用、音频位置/倍率、登录状态、必要结果与分享渠道等有限维度，不上传账号 ID、OpenID、个人资料、正文、操作键、完整路由 query 或登录令牌。随机标识不等于完全匿名，也不保证跨设备识别同一人。

业务写操作在确认成功后通知统计，统计异常不改变业务结果。操作键只在本地作有界去重，不上传。SDK 初始化期间仅暂存已同意后发生的有限事件，撤回或进入后台即清除。

在对应友盟测试/生产应用中登记同一套32个事件ID后，可按内容类型创建“进入页面→登录→开始→完成”漏斗并查看访问留存。报表仅覆盖同意统计的访客，不能用作所有访客或业务成绩的完整账本。收藏、分享作为辅助指标。

## SDK 与验证边界

SDK 锁定 umtrack-wx 2.8.0，useOpenid、autoGetOpenid、uploadUserInfo、enableVerify、debug 均为 false。不提供微信 AppSecret，不自动调用微信登录、用户资料或剪贴板接口。

构建插件给原版 SDK 注入独立微信端口作用域，不修改全局 wx，也不修改 node_modules 中的 SDK 源码。公开生命周期与底层微信异步回调双层检查统计授权/平台模式，避免 SDK 内部初始化及计时器在撤回后继续采集。微信分享摘要模式不启用统计。

未启用统计的构建替换为空实现，并在条件编译阶段移除统计说明。替换路径同时适配日常src输入和发布命令的隔离输入副本。启用SDK的测试和生产包采用512KiB回归预算；未启用仍为450KiB。原有平台包体上限、转换余量、页面及音频检查继续执行。

本地检查使用 pnpm check、pnpm test 和隔离 uni build，不调用带 OSS 同步的小程序测试发布命令。本轮生产接入仅完成代码和本地配置；真实上传、体验版切换及发布不属于本轮交付。

## 核心业务补充口径

2026-11-09新增18项后为33个事件，2026-11-10取消联系方式保存事件后为32个事件，桌面sample.txt保持每行“事件名, 简短记录时机”。入口、内容选择、标签和分类由明确用户操作触发；相同标签/分类重复选择、登录快照或本地历史恢复不记成切换。列表内容点击与下一篇各用独立入口，不在组件和公共导航重复记同一点击；底部导航到达仍复用page_enter。

新增维度白名单为target_page、tab_id、category_id、expanded、action、stage、error_kind。页面路径去除query；查词只传公开内容/版本及紧凑行号/位置。打卡展开不发送所选历史日期。反馈/资料成功仅按固定接口方法和路径映射，既不读取冻结请求正文，也不上传私人反馈对象编号。成功复用原操作键本地去重和回执恢复；上传截图/头像和阅读回执不会误记为反馈提交或资料保存。

business_error的action是固定动作；stage为validation/request/download/open/upload。error_kind只允许validation/network/unauthenticated/forbidden/content_unavailable/conflict/result_unknown/platform/other。result_unknown表示结果未确认，不等同于服务端最终失败，不触发任何自动重试。统计分类和发送异常不改变原业务流程。

错误观察限定主动操作，后台权限核对/刷新、预加载、主动取消与已失效异步回调不产生新业务错误。反馈自动恢复只读查询不记失败，但查询确认的成功仍按原键记录一次。study_note_ready在最后一次校验完成、调用原生文档打开之前通知，仅表示本地准备完成；异步取消后的文件与错误不进入统计。

全部33事件、错误辅助层和调用通过统计启用条件编译；测试与生产启用时均保留，未启用时移除，不改变后端接口或数据结构。工作继续保留在本地test分支，实际测试/生产服务端接收仍待用户验收。
