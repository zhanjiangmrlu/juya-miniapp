# 临时暂停的学习功能（2026-11-11）

本轮按用户确认方案在 test 分支实施。集中开关位于 `src/shared/constants/learning-features.ts`，默认全部 false，保留原实现：

| 开关          | 暂停后的行为                                                 | 恢复要求                                             |
| ------------- | ------------------------------------------------------------ | ---------------------------------------------------- |
| authorization | 账号学习授权区域及其请求隐藏；非免费内容显示“暂未开放”       | 与 API LEARNING_AUTHORIZATION_ENABLED 一起修改并发布 |
| dictionary    | 不绑定正文查词点击，不预加载正文词音；提供系统长按选词复制   | 与 API IN_APP_DICTIONARY_ENABLED 一起修改并发布      |
| listeningSync | 无随音频变色、尾迹、自动滚动或同步高亮提示；静态重点色带保留 | 重新设为 true，回归音频及阅读位置                    |

登录、隐私同意、收藏、免费内容学习笔记、全文播放、预置词发音、倍速、译文和进度保存保持原业务规则。服务端统一决定已发布内容是否免费；旧授权账号也不能打开非免费内容。API 增加 content_not_open / lookup_unavailable 原因值，客户端保留对旧授权错误的显示兼容。

正文选词交由微信/操作系统，是否出现其他软件的查词菜单依赖手机、微信和软件安装情况，小程序不会直接启动任意第三方词典。iOS、Android 须分别真机长按选词/复制验收。

## 小程序版本更新

`src/services/app-update.ts` 的协调器由 App.vue 启动/前后台生命周期调用。注册一次更新监听，无更新不提示；下载就绪后前台提示“更新提示”，确认“立即更新”才重启，“稍后”后下次进入再次提示。同一次进入不重复弹窗，后台就绪等待前台。下载失败提示检查网络后重新进入；不支持更新接口的平台安全跳过。

自动化用受控平台端口验证就绪、取消、跨前后台、重复回调和失败；真实新版下载与 applyUpdate 重启仍须微信真机验收。本功能需要当前运行代码已经包含更新协调器；开发版上传不等同于线上新版本发布。
