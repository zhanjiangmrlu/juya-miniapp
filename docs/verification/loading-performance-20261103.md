# 小程序列表与整段音频加载优化（2026-11-03）

按用户确认的方案，先压缩资源与优化代码，不新增 CDN、扩容或降低音频码率。实施在原目录的 `codex/miniapp-loading-performance` 分支，保留原运行配置、原图和业务数据。

## 已实施

- 六张原始背景853×1844及SHA保持不变；5张插画生成q82 WebP，纸纹生成q82 JPEG，使用内容哈希地址。单张44,184—69,636B，页面插画加纸纹最大120,602B；原列表页两张背景合计约3.44MB。显式WebP、失败一次回退原PNG，布局尺寸及位置不变。细纸纹会有轻微柔化，实际已对照查看profile和paper。
- `scripts/compress-page-backgrounds.py --check`可复现所有变体；开发/H5静态白名单及MIME同步。静态发布顺序及长期缓存要求见 `resources/oss/backgrounds/serving.md`。
- 听读分类统计与文章列表并行，任一成功独立显示、失败独立重试。分类直达不再重复请求第一页，保留分页/滚动与账号边界。
- 听读详情复用场景完整音频准备器，进入页面下载准备，点击时已完成用临时文件，未完成取消后台下载并立即流式播放，继续播放前鉴权。
- 场景完整音频准备结束后才开始后台词汇预取，主动点词不受限制。普通hide/离页/会话变化回收；大图预览保留既有播放行为，但隐藏期间不启动后台词汇，返回后恢复队列。此处是对方案“离页清理”的兼容裁决，避免回归原有大图不中断播放。
- API配套提交 `7c6c2e2`：请求内批量状态/授权/版本/媒体、分类聚合统计，缩略图固定144×216/WebP60，缓存前继续验权，无契约或数据库迁移。
