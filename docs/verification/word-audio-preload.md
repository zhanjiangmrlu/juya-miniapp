# 场景词汇点读预加载验证

日期：2026-10-19。工作区：`test` 分支，保留实施前已有改动。

## 行为

- 场景正文返回后串行准备当前卡片词汇；主动点读有独立通道，同词复用进行中的任务
- 微信小程序下载到 `uni.env.USER_DATA_PATH` 下本功能独占的缓存文件；默认下载临时目录只读，不能用于主动清理
- 缓存命中时在点击事件内同步启动播放器；未准备好时继续显示加载状态
- 缓存有效期从发音地址请求开始计算，最多四分钟；离页、会话变化、版本变化及下线时停止任务并删除文件
- 异常退出遗留的自有过期文件在下次下载时清理；不清理其他业务文件
- H5 提前准备受控地址，继续使用现有浏览器播放器

## 自动化覆盖

准备服务、文件下载及场景页面测试覆盖任务去重、后台串行、点击优先、快速切词、同步缓存命中、有效期、下载失败回退、访问失效、迟到响应清理及页面隐藏后迟到正文不启动准备。原有完整音频、暂停、倍速与互斥播放测试继续通过。

验证命令：`pnpm test`、`pnpm check`、`pnpm build:mp-weixin`、`pnpm build:h5`；另外以 `local-share` 模式更新开发者工具实际打开的 `dist/local-share/mp-weixin`。

## 开发者工具实测

微信开发者工具 Stable 2.02.2608080，模拟器基础库 3.17.4，通过当前 `dev-api.juyayingyu.com` 服务读取真实场景与发音，不替换接口响应或播放器。

进入“为戏剧社挑一个剧本”后观察到 8 次发音请求、8 次成功下载，预加载期间无播放。缓存完成后，首次点读和重复点读均使用下载文件；点击事件处理开始到原生 `onPlay` 分别约 21ms、0ms，期间未增加发音请求或下载。离开场景后，检查这 8 个自有缓存文件全部不存在。

计时通过临时包装页面事件与原生播放器完成，测试结束后恢复原方法。计时代表模拟器事件耗时，不代表真机声卡出声延迟。

代码配置的生产 API 为 `https://api.juyayingyu.com`，本地分享配置为 `https://dev-api.juyayingyu.com`。对应域名需配置为小程序的 request 和 downloadFile 合法域名；代码仓库不能证明微信公众平台生产配置已经生效，本次未更改公众平台配置。

真机首次进入立即点读、弱网、iOS/Android 出声延迟尚未实测。预加载未完成时保留等待与重试，不保证所有点击零等待。

## iPhone 测试体验版问题续查（2026-10-19）

用户反馈测试环境在 iPhone 扫体验码后，首次和再次点读均提示不可用。只读检查云端测试环境：三个小程序容器健康、没有重启或 OOM；23 个发音任务全部成功，配置使用 MP3。抽查三个实际 OSS 音频文件均为 `audio/mpeg`，长度、SHA-256 和 MP3 文件头符合保存记录。以上证据只证明合成及存储可读，不代表手机端请求和播放成功。

发现小程序将音频下载为没有扩展名的自有文件，可能影响 iPhone 原生播放器识别。现改为下载完成后读取前 12 字节，识别 MP3/WAV，再使用对应的 `.mp3`/`.wav` 文件名；不改变音频字节，不将 WAV 误标成 MP3，离页和到期仍只清理本功能文件。同步更新原文件下载测试的文件系统替身。词汇加载阶段增加“正在加载发音…”提示，真实失败仍保留重试，播放时不显示失败提示。

`pnpm check`、测试环境与本地分享微信构建均通过；本轮未重跑自动化测试。开发者工具通过本地分享真实接口点读 `play`，原生 `onPlay` 确认使用 `.wav` 文件，页面显示“播放中”且无不可用提示；临时播放器诊断方法已恢复。该观察来自桌面模拟器，本次无扩展名兼容修正是否解决 iPhone 的实际故障，仍须更新体验版后由用户真机复核，不能记作真机验收通过。
