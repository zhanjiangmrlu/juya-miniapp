# CHG-0040 隐私同步修复与本地测试热更新

用户要求移除两条内部状态提示，排查并修复同步失败，再在本地使用测试环境数据实时验收。本轮只修改本地 test 工作区和本地微信编译项目；未推送、部署远程服务或上传微信开发版。

## 根因与修复

微信构建链把隐私服务中的动态 import 转为 `await "./platform.js"` / `await "./api.js"`。解构字符串拿不到 sendRequest/session，调用时异常，尚未发出 HTTP 请求就落入通用“统计状态暂未同步”分支。H5 源码测试不能发现该编译产物问题。

privacy.ts 与 consent-coordinator.ts 改用静态模块引用，修复匿名政策、本人许可读写和启动确认的同类问题。移除“正式配置未就绪，真实统计保持关闭”和初始化“统计状态暂未同步，保持关闭”两条提示；初始化完成前及失败时开关保持关闭，主动操作错误仍单独处理。真实 SDK/传输硬关闭和正式材料缺失时的 legacy 行为保持。

新增回归直接加载真实微信编译 CommonJS 模块，只替换 uni 网络/存储边界，执行匿名协议 GET、带会话许可 GET/PUT、启动时账号确认；修复前复现 TypeError/请求未发出，修复后通过。静态引用暴露两处旧字体/页面测试缺少原生存储端口的夹具问题，补全夹具，未修改产品会话鉴权。

本地旧 8292 确有新路由 404，但当前微信开发工具实际项目之前连接 8293，其新路由存在，故不能用旧 8292 的 404 解释本轮截图。最终根因由编译产物和真实开发工具重现确认，无需重启或修改这两个后端实例。
