# CHG0039 联系方式收集退役（2026-11-10，仅本地）

在现有 `test` 分支取消联系方式展示和收集，保留账号资料、收藏、学习授权、反馈、头像昵称编辑、学习记录和原水彩/字体资源。未推送、部署、上传 OSS 或微信；未连接真实业务账号或改动真实业务数据。

## 实现与兼容

- 账号页删除联系方式入口、掩码和展示值，删除联系编辑模型、校验常量及专用类型
- `contact-edit` 路由与页面注册保留，页面只在加载时 `switchTab` 到 `Routes.PROFILE`；不恢复表单、不读取联系方式、不触发登录。原 `safeTarget` 对旧联系地址返回账号页的规则保持
- 当前账号的操作记录在服务初始化及取得操作上下文时清理旧 `contact-save` / `contact` 动作和旧 `/api/mini/v1/me/contact` 路径；不枚举其他账号，不清除学习待确认记录。退役写入与重填被本地拒绝，旧回执不查询或重放
- 移除 `contact_save` 事件、动作枚举、成功映射和使用说明；当前事件数为32。原友盟环境隔离、SDK披露、登录页勾选同意及撤回行为保留
- 隐私核心段落采用设计稿的游客免费浏览、主动登录识别同一账号、主动设置头像昵称和不收集手机号/微信号文案；保留2026-11-09友盟统计披露和同意逻辑
- 配套 OpenAPI 与生成类型由主任务统一同步；本次前端提交不包含这两个生成契约文件
