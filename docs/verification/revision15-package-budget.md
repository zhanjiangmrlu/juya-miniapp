官方CLI原包上传返回 `main package source size 2100KB exceed max limit 2048KB`。该次CLI虽然退出码为0，但没有上传回执，因此不是成功发布，版本仍为 `1.5.0-test.1023.1`。

新增验证读取真实构建目录，累加主包中未压缩文件，按 `app.json` 的分包根目录排除分包，拒绝符号链接，不以ZIP体积替代微信主包计量。旧包主包1,887,023字节，微信处理后约有14%膨胀；门禁采用更高的20%转换膨胀估计，随后还必须保留至少102,400字节。默认微信生产构建和测试构建都会执行门禁。
