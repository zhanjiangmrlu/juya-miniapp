基于 `test` 的 `56ded7b33aaa1883bef4d7a39bfa0b72eae44135`，仅在隔离工作树完成本地实现。配套需求、接口与52项验收台账由 API 仓库的 CHG0043—0045 合并方案维护。本记录覆盖小程序客户端；没有推送、部署、上传 OSS/微信或操作共享数据库。

## 实现

- 首次进入“雅思词汇”仍打开“场景学习”，默认“图解词汇”，两个 Tab 分别显式请求 `scope=uncompleted&content_type=illustrated|intensive`。两类独立保存可信列表、已读页、错误和位置，主动换类回顶部。
- 计数读取服务端完整集合的 `total`；空态使用同一响应的 `type_published_total`。游客显示“词汇列表”，不虚构已学数；本人显示“待学词汇”。受限摘要保留，继续显示“暂未开放”。仅本人待学为0且本类有效发布数大于0并成功刷新时显示“本类词汇已全部学完”。全学完提供学习记录与另一类入口。
- 必须同时确认分类就绪和类型发布计数；缺失/未就绪不能变成空列表。明确配置异常或撤回就绪会清除旧类型内容；普通网络失败保留原可信内容并标明失败，不填0。
- 新待学来源统一 `learning`，带 `content_type` 创建队列和导航。队列验证来源类型快照、跨页推进、不循环；最终正文再核对类型及本人完成状态，跳过并发改类或完成的候选。收藏/记录/某日复习规则和既有幂等动作名保留；旧 `learning_notes` 仅留作兼容，不由新双分类入口发送。
- 详情、PDF 与显式登录保留分类上下文。登录成功/取消只读恢复 Tab、已读范围和位置，立即清理旧身份数据；登录不自动播放、打开 PDF 或提交完成。完成未知仍通过原操作回执重查，未确认时不推进队列或本地减数。
- 复用水彩、四种字体、场景卡与状态组件。Tab 自然文字宽度、32px间距、44px点击高度、2px绿色选中线及1px浅基线。按本次设计移除列表头额外连续/累计打卡行，保留已学场景数、学习记录、账号入口及原统计数据。
- 从配套 API 导出的 OpenAPI 生成类型，按仓库格式整理；新增 `source_hint` 契约的既有词汇测试夹具同步补空提示。没有重建已取消的运行时 Mock，隔离测试继续使用原 session/组件/原生端口夹具。
