# 词汇发音恢复与弱网优化验证

日期：2026-10-27；本地分支：`test`；基线：`f5c1143`，与 2026-10-26 已知体验包一致。实现验收时改动尚未提交或上传；后续上传状态以官方工具回执为准。

## 行为与可复现缺陷

- 重点词汇、查词弹窗点击立即进入加载；音源准备与逐次联网验权并行，只有当前尝试获准后才播放。整篇音频原有播放、暂停、续播、进度和倍速逻辑保留。
- 词汇地址就绪后，前台最多再等待 500ms 下载；未完成则取消下载、复用同一受控地址播放。迟到文件回收，不能覆盖当前音源。
- 网络或临时服务错误最多恢复两次，间隔 250ms、750ms；本地文件错误最多重新准备一次，计入同一预算。永久合成失败、权限拒绝和冷却不循环。
- 音频地址失效和会话失效分别处理。错误文件按实际文件大小读取，最多接收 4096 字节；避免微信拒绝超出文件长度的读取而丢失 `speech_grant_expired`。
- 每个词汇音源使用独立底层上下文，旧上下文迟到事件不能改变新选择。列表、弹窗和整篇之间切换时取消前一个词汇的前台准备任务，保留已就绪缓存及唯一后台任务。
- 已用失败用例复现慢下载无限等待、403 回退、后台抢占、权限结果迟到、短错误文件读取及跨入口取消缺口；均经过失败到通过验证。这些不是截图故障在手机上复现的证据。

## 验证结果

- `pnpm test`：73 个文件、358 项测试通过，包含整篇播放、倍速和点词回归。
- `pnpm check`：格式、ESLint、Stylelint、类型检查通过。
- `pnpm build:mp-weixin:test`：12 个页面配置、底部导航和主包预算检查通过；主包源文件 368522 字节。
- 独立代码审查发现的错误文件读取长度、跨入口取消两项已补失败测试并修正。
- 测试构建输出：`dist/build/mp-weixin`。开发者工具原来打开的是旧 `dist/dev/mp-weixin`，不能用旧目录验证本次修改。

## 诊断与真机验收

测试构建控制台按 `[word-audio]` 过滤分段记录：取址、下载、文件格式、验权、原生启动的耗时、状态及错误码。内存最多保留 100 项；不记录原始错误文案、完整地址、用户身份或凭证；生产构建不采集。

尚未取得新构建在 iPhone、Android 微信上的实测结果。用户已于 2026-10-27 授权提交到 `test` 并上传测试版本 `1.5.0-test.1027.1`；上传成功和设置体验版需分别核验，不能仅凭构建成功推断。真机需分别执行：

| 场景                       | 验收要求                                                     |
| -------------------------- | ------------------------------------------------------------ |
| 正常网络首次点读与同词重播 | 音源正确，无叠播；本地缓存命中不重复下载，仍逐次验权         |
| 弱网进入即点及缓存后点读   | 立即加载，区分验权、取址和原生启动耗时；不因后台队列额外等待 |
| 断网、恢复网络及重试       | 恢复次数受限，最终失败保留原位重试；恢复后可以重新播放       |
| 快速切词、列表与弹窗切换   | 仅最后目标可出声，旧回调不覆盖新状态                         |
| 授权撤销、到期与账号切换   | 未获当前权限绝不播放，旧会话资源失效                         |
| 离页、返回及切到整篇音频   | 不出现迟到自动播放；整篇位置、暂停及倍速行为不变             |

模拟器和自动化不能代替手机实际出声验收；在取得对应诊断前，不宣称用户截图中的偶发报错已经在真机解决。
