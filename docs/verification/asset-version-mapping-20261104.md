# 固定逻辑名与资源版本映射验收（2026-11-04）

## 结果与范围

本地实现已完成，基于test分支5e606b1。固定文件名覆盖后，下一次构建生成新内容哈希地址；包内映射锁定当次版本，旧对象继续保留。首页和两张分享图已使用固定逻辑名，背景、品牌及字体统一通过解析器取得地址；分享缓存文件名、大小、尺寸随映射变化。本轮未提交、推送、上传微信包或发布生产资源。

## 验证

- `pnpm check`通过：Prettier、ESLint、Stylelint及TypeScript检查全部成功

- 全量109文件/558测试通过，含真实两次微信编译：同名替换后图片地址变化、尺寸变化，分享图缓存元信息更新，旧编译包仍返回旧地址
- 内容变化发生于构建清单建立后时，发布器在读取配置和远程访问前阻断；同内容逻辑别名与已有哈希文件合并为同一个远程对象
- H5构建成功，23个逻辑资源逐个核验输出内容SHA与来源一致；精确预览索引优先保证真实版本地址对应正确字节
- 测试及生产微信构建均通过18页面、三Tab、主入口音频及包预算校验；均不包含design-assets原图，编译JS不含本机目录或OSS私钥字段，两环境静态域名相互隔离
- 本地微信处理前主包：测试450238 B（439.7 KiB），生产449157 B（438.6 KiB）；生产比此前445668 B增加3489 B（3.4 KiB）公开映射及解析代码，仍低于450 KiB回归约束。这不是微信官方转换后的包体
- 真实测试构建调用自动同步：新增0，复用13，全部公网SHA、MIME及一年immutable缓存校验通过；固定名副本未产生重复远程上传
- 真实测试桶独立随机前缀探针：首次1次上传；新增2张并同名替换1张后3次上传；再次同步0次上传。确认旧版本仍能读取，最后清理4个本轮临时对象并逐个确认不存在；没有清理业务资源
- 独立代码审查确认无功能阻塞；修复一条旧预览测试对本机源文件名的过度约束，改为断言返回字节的内容哈希

临时探针非敏感回执保存在本机忽略目录 `.private/asset-map-probe-result.json`，生产发布链路只在隔离端口测试及普通生产构建验证，本轮没有实际生产写入。实际微信真机视觉验收及新版本上传未执行。
