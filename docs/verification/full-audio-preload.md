# 完整对话音频预加载验证

日期：2026-10-19。工作区：`.worktrees/juya-miniapp`，`test` 分支，保留实施前已有改动。

## 行为

- 场景正文返回后，在所有网络类型下后台准备当前卡片整篇音频，与词汇准备分别管理；不阻塞正文，不自动播放
- 微信小程序复用可取消下载与自有文件清理机制；准备完成后，点击同步使用本地文件
- 提前点击会取消整篇后台下载，通过已获取或正在获取的同一受控地址开始网络播放，不等待完整文件下载
- H5 提前获取地址，在实际整篇播放器上设置 `preload="auto"`；点击、暂停续播与重播复用同一播放器，避免重复设置相同地址
- 背景下载迟到结果不会覆盖播放中或暂停的音源；播放失败清除准备缓存，重试重新获取地址
- 缓存按当前页面、会话、卡片、发布版本和音频引用隔离，从准备请求开始计时，最多四分钟；失效、离页或会话变化时取消并清理文件
- 保留原图预览期间的音频生命周期，以及整篇与词汇互斥、暂停续播、拖动、重播、倍速行为
