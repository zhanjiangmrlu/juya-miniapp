# 听读横向滑动与授权展示修复（2026-11-11）

用户反馈：主题听读页面左右滑动后内容偏移、左侧文字被截断；场景学习顶部仍出现“未授权”。本轮仅修改小程序，保持免费内容访问规则、服务端授权数据与原休眠分支。

## 修改

- 场景列表全部场景/含学习笔记两分区的顶部姓名、打卡状态保留，原授权状态拼接受现有暂停开关控制；无授权、有效、过期均不展示
- 学习笔记卡片旧缓存或保留输入中的“授权可学”也加入开关控制；非免费显示“暂未开放”，学习与复习记录保留
- 反馈截图加载失败改为可理解的重取提示，不显示技术性的“截图授权”字样；登录和隐私协议规则保持
- 听读页限定宽度并裁切横向溢出，微信页面单独关闭横向滚动；长文本自然换行，词汇/音标行可换行且不挤出屏幕；没有禁止 touchmove 或纵向滚动
- 共用播放器未传同步状态时仅显示普通播放/暂停提示，不再回退显示“高亮与尾迹”或“跟随音频”；明确恢复同步提示的分支保留

## 验证

- 新增三种授权状态在两分区的显示回归，先复现遗漏再通过；学习笔记卡片两种完成状态先复现授权文案遗漏，再通过
- 普通播放器播放/暂停不出现同步提示，显式同步状态仍可恢复；全量140文件844测试、pnpm check、H5/微信local构建及包预算通过
- 使用与截图相同的 A Lazy Weekend 文章做只读检查：Chrome H5 和微信模拟器初始画面没有自然重现手机偏移；另以长英文/长链接复现宽度390扩至1519的横向溢出，作为边界修复依据
- 修复后320/390/430宽度下，原文与长内容均不撑宽页面，尝试横向滚动后scrollX=0；纵向滚动900，sticky导航top=0，长文本换行而非直接截字
- 微信编译实际包含当前页横向限制；模拟器390宽表达区342宽、左留白24，滚到下部后仍对齐，固定隐私浮层展示正常且可关闭

独立只读审查发现学习笔记卡片的P2遗漏，已补开关和RED→GREEN回归；没有其他确定的P0/P1/P2。

**真实 iOS/Android 的左右手势尚需手机复验。** 模拟器viewport接口返回的scrollWidth在修复前后均为398，不能据此宣称真实手机所有横向手势已验；本轮以源码限制、编译结果、浏览器溢出测试和模拟器可见布局为已验证范围。

无新增埋点事件，sample.txt不变。小程序修复包的实际上传版本与回执另行记录；后端API、测试库和生产不需本轮更新。
