## 统计与独立复核

每次账号/许可代际使用新的官方 SDK 实例、内存存储、计时器和请求集合，不读取旧设备队列。使用随机 UUID、内部业务账号，关闭自动 OpenID、用户资料上传和埋点验证。只允许官方统计域名的两个已核实路径；不改写 SDK 请求载荷或伪造响应。

五类业务事件先经服务端校验当前可信账号、协议/许可 revision、时间、对象归属及操作回执，再调用 SDK。接口 accepted 是发送授权，不代表友盟已经接收；自动会话及页面字段按用户新授权范围披露。服务端 collecting 在无许可/通道关闭时为 false，允许的客户端状态为 null；界面“当前已开启”依赖本机 SDK 实际运行状态。

独立只读复核发现并关闭五类问题，均有修复前失败及修复后通过证据：

1. 关闭 PUT 成功后，迟到 GET 不能覆盖新 revision；写成功使并行读取失效。
2. 授权 401/403/409/503 后先阻断，目录与许可完整恢复前不重启；过期身份/许可回调不影响新状态。
3. 会话、资料账号与隐私状态账号严格相同；新账号不能继承旧账号许可。
4. 目录响应只采纳最新请求；被替代的请求明确失败，不用缓存假装恢复成功。
5. 隐私页刷新失败时，已开启统计仍正确显示并允许关闭；离线同步失败仍立即停 SDK、保留本地关闭记录。

真实 test 模式微信编译产物使用 fixture key 执行 SDK 主链路：同意前无请求，允许后服务端授权/官方 SDK 正常执行，撤回后停止；未使用真实网络或真实账号发送。独立离线集成探针覆盖实际组件、隐私服务、桥和官方 SDK，关闭后无新增请求。
