# 修订12小程序视觉修正验收

2026-10-17，本次只修改 `juya-miniapp`。依据工作区 `句芽英语-原型与设计稿/需求基线-20261017.md` 和 `本地设计预览/index.html` 的修订12页面；管理后台、API与云端部署不在本次变更中。

## 原因与范围

之前的重建提交 `0f489e1` 用通用叶子图标、另写的营销文案和另一套布局实现登录页，遗漏需求基线对水彩品牌、字标、字体和文案的要求。此前核心流程验证只能证明业务流程，不能作为视觉还原验收。本次使用原型资源和逐页截图纠正这些偏差。

| 页面        | 本次修正                                                                                           |
| ----------- | -------------------------------------------------------------------------------------------------- |
| U00         | 原水彩、品牌字标、标语、白色登录卡、文案、同意区域及两行底部说明；默认不勾选，未同意点击时就近提示 |
| U00-P1      | 居中隐私弹层，保留真实产品的完整隐私说明                                                           |
| U01/U02     | 问候、英文标题、横排统计、卡片与收藏数量、横排圆角学习/收藏导航                                    |
| U03         | 场景缩略图与提示、绿色音频栏、双语章节、对话说话人、高亮和词汇发音按钮                             |
| U04         | 场景大图关闭、标题和缩放控件                                                                       |
| U05         | 安全摘要缩略图、删除/下线说明、取消收藏与返回原列表                                                |
| U06         | 记录统计、切换标签、日期列表与展开状态                                                             |
| U07/U08/U09 | 只读资料、头像昵称编辑、选填联系方式的字体、间距、分隔线及操作区域                                 |
| 公共状态    | 空状态、未保存确认、字体与颜色、页面导航和底部安全间距                                             |

真实API、会话恢复、收藏/完成幂等状态、音频互斥与未知结果查询继续使用原业务实现。U05只请求 `purpose=summary` 的安全缩略图，不恢复下线正文或音频；返回使用原页面栈。

## 已执行验证

- `pnpm test`：16个文件、42项测试通过，包含登录同意拦截、隐私查看、失败重试、底栏切换及U05安全缩略图/返回行为。
- `pnpm check`：Prettier、ESLint、Stylelint与Vue类型检查。
- `pnpm build:h5`、`pnpm build:mp-weixin:test`：构建并检查9个页面和学习/收藏两个入口。
- H5以390×844视口抓取U00—U09的主要页面；U01—U09使用本地隔离合成账号和实际新API。未执行资料、收藏、完成或打卡写入。
- 学习→收藏→学习实际切换后，各自高亮正确，只有两个入口，无重复原生底栏，无横向溢出。H5直接刷新时原生底栏未建立的情况已使用失败回调处理。
- U00同尺寸几何核对：品牌区域y=88、白卡y≈487.08、主按钮y≈648.05、底部说明y≈774.03；与原型对应位置的差异小于0.1px。该结果仅针对这些几何量，不代表整屏像素完全相同。
- 微信开发者工具Stable 2.02.2608080模拟器实际查看U00水彩/字标、未同意提醒、隐私弹层打开与关闭，未进行真实微信登录或上传。

## 本地查看

H5热更新在 `http://127.0.0.1:5174`。微信开发构建通过 `pnpm dev:mp-weixin` 持续生成，开发者工具应导入 `dist/dev/mp-weixin`；`dist/build/mp-weixin` 是一次性构建。本机开发配置连接测试API，热更新代码目录与后端环境是两个独立概念。

当前开发者工具预览仍打开一次性构建目录，CLI服务端口未开启，未改变其安全设置；需要在工具中导入开发目录才能持续接收改动。

## 验收边界

这是主要页面的视觉修正与回归检查，不是全部状态或真机验收。微信状态栏、胶囊、原生确认/输入/勾选控件随平台绘制；真实手机上的字体、手势、头像选择、音频播放及拖动仍需验收。

真实接口目前没有原型中的英文场景名和列表词汇/语块计数，页面没有填入原型样例冒充业务数据。隐私说明保留正式产品正文，不使用原型演示说明。部分本地资料图片处于加载失败状态，显示重试入口；截图不等于云素材链路验收。
