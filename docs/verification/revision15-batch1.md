# 修订15批1：学习分流与来源队列

依据：2026-10-22已确认《开发方案-整合03修订15-待确认.md》；CHG-0017；T148—T159、T198

## 实现

- 学习列表消费服务端未完成范围与 `published_total`，区分无发布和本期全部学完；保留统计独立加载。列表分页逐页追加、按ID去重，失败保留可信内容并重试同一页
- 统计下方增加独立整行学习记录入口，保留三个统计按钮与两底部导航。卡片显示未开始、学习中或已学；缩略图兜底请求使用 `mark_started=false`，避免列表预加载造成假阅读开始
- 学习、收藏、全部已学和某日记录点击时建立服务端来源快照。创建复用持久幂等，未知结果先查询操作回执；快照仅在当前账号内存中持有，路由必须匹配快照及当前卡片，直接单卡不继承旧来源
- 详情确认完成后留在当前卡，提供下一张；今天已完成可直接继续。收藏中未学与已学分别处理学习和复习。推进重新读取当前状态，然后按固定索引读取后续资格；失效项跳过，分页失败不误报结束
- 结束弹窗分别显示本次学习、复习、收藏范围，可返回学习页或留当前详情。直接单卡完成后仅前往学习页。快照过期不会把当前有效卡误判为下线
- 下一张先预读正文，成功后提交来源游标并通过 `redirectTo` 替换当前详情，更新路由且保留返回来源列表栈；读取或原生导航失败保留当前卡与游标，重试同一目标。账号绑定的一次性预取正文避免替换路由后重复GET。旧音频随页面销毁停止，译文默认收起且不自动播放
- 同版本正文位置使用top、对话行、词汇和语块语义锚点，按各组件真实布局测量。真实滚动后在hide/unload保存并合并同位置请求；重新进入按当前设备布局恢复。旧版本不猜测锚点并提示从顶部开始；不跨账号写入
- 持久待确认完成在重新进入和重新显示时继续阻止提交与推进；主动恢复原操作并重查当前状态后才能继续。首次原生进入也等待导航结果，失败还原原来源并显示可见错误

## 边界

- 本批不添加正文查词、反馈或原生分享入口；直接单卡完成语义为后续分享批次提供基础
- 服务端快照24小时有效，页面进程重建或重新登录时退回安全单卡语义，重新从来源列表点击可建立新队列
- 阅读开始、完成与计数的持久性由统一API验证；前端只消费服务端真实状态，不自行补写完成或打卡
