## 本轮行为

- App 启动与首页 onShow 不再连接协议告知调用链；首次、次日、分享、重入、前后台及政策版本变化均不能自动弹协议/登录提示。旧入口退化为无副作用兼容函数；历史确认、设备记录与隐私设置保留。UpdateManager 独立更新提示保持。
- 免费图文、释义、译文、原图和已发布 PDF 元数据入口继续公开。游客详情不创建可加载的全文或预置词发音准备任务、不获取资源票据/预取/设置媒体 src；点击全文播放、预置发音或学习笔记才提示登录，三种 ConsentAction 分别标识来源。
- 主动提示和登录页必须读取正式政策；失败保留重试与继续浏览，不能 fallback 到 legacy 协议登录。新确认记录使用本次 ConsentAction；已有当前版本的有效确认复用其历史来源。
- 多个缓存页面的 AppLoginPrompt 共享同一次在途政策读取，成功/失败后释放共享 Promise；下一次提示重新核实。保留 privacy-service 的目录代次校验，避免较旧目录覆盖新版本。
- 取消、失败和来源消失同步取消尝试代次；政策重验期间的迟到结果不能继续登录。成功仅刷新并只读恢复原来源，不保存游客成绩或自动播放、发音、打开 PDF、收藏和完成，仍需二次点击。
- 401 清理全文/词音轨、在途准备、资源地址和私人 PDF 文件；当前已知免费的正文及展示继续保留，清除本人状态。背景播放器失去所有者后，迟到系统 onPlay 会立即 stop。旧会话或旧页面不能继续使用缓存文件。
- 游客仍可调整公开音频元数据的显示位置和倍速，不触发保护资源请求。授权、内置正文查词、动态高亮/跟随开关保持 false；静态重点色带、系统选词和原生宽度修复保留。真实统计 SDK 仍硬关闭，无新增事件。

API 沿用既有路由与响应，未新增 capability 字段或修改生成类型；无身份的音频/PDF/发音为 401，免费图文 can_learn 语义保持。配套见 [API 资源登录契约](../../../juya-api/docs/implementation/chg-0042-resource-login-contract.md)。
