# 固定逻辑路径的资源版本映射实施计划

用户已确认：只在重新打包后使用新图，旧包继续使用旧资源；项目文件名与代码引用保持稳定。仅本地实施和资源验证，不推送或上传新微信版本。

**Architecture:** 统一Node资源扫描器产生source逻辑名、实际哈希file、bytes/width/height及SHA。Vite把公开映射注入包，上传器读取同次构建清单并在任何外部写入前核对资源未变化。测试/生产触发规则沿用现有流程。采用image-size2.0.4在Node侧读图片元信息，不进入前端。

- [x] 抽取共享资源清单模块，新增稳定逻辑名，兼容现有哈希名及7份固定历史归档。公开映射不含二进制内容、凭据和本机路径；按实际哈希key合并重复内容条目
- [x] 新增assetInfo/assetUrl统一解析器和Vite版本插件，编译清单写每次构建独立的dist元数据目录；开发/H5预览按同一映射服务资源，文件变化触发刷新但不上传
- [x] 首页采用稳定逻辑名；远程背景、品牌、字体与分享入口接入统一解析。分享缓存的实际file/bytes/尺寸从映射获取，旧哈希资源/旧包URL继续可用；本地图标及兜底不变
