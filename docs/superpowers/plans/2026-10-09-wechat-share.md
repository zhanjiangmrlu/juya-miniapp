# 首页与场景微信分享实施计划

> 使用 executing-plans 在当前 main 执行，遵循测试驱动与最终代码审查

目标：首页及场景详情支持好友、朋友圈分享，统一公开入口为 `useWechatShare()`，补充发起分享及分享回流统计

约束：H5 不提供微信分享；私人页面不接入；统计不影响分享；链接只传场景 ID 与固定来源字段；接收者沿用现有权限校验；不声明分享发送成功

架构：组合函数集中生成标题、固定公开封面及安全路径，并注册生命周期和埋点。页面传入配置及原生分享钩子，保留 uni-app 编译器识别所需的显式导入。回流由已有统计状态机处理，SDK 仍不接收完整 query

文件：`src/shared/use-wechat-share.ts`、共享 sharing 类型/枚举/常量、首页与场景详情、analytics-service 与埋点字典、镜像单元测试、固定公开分享封面

重点核验：冷启动已授权但 SDK 尚未就绪、初始化期间撤回、无权限/过期场景响应、朋友圈单页模式、取消分享不会被记成成功

Ruling：分享入口限定首页与场景详情，内容学习子页通过详情入口分享；这是用户最终确认的两类页面，不扩大到进度或资料页

Ruling：回流只在分享落地页首次 onLoad 上报，App onShow 恢复不重复上报；同一已存在页面的恢复不会增加回流，统计的是分享落地页创建次数，不是送达量或独立用户数
