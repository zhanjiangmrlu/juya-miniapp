**目标：** 记录进入各页面、前台停留及具体内容的音频操作，供本地验收

**设计：** 复用 SDK 页面生命周期，在统计服务内统一去重和结算停留；授权或 SDK 就绪前不计时，后台时间排除。复用共用音频控制器的操作入口，点击播放/暂停与原生播完/失败分开，附内容类型、ID、版本、词条引用和媒体位置，不上传正文或音源 URL。生产条件编译移除新增采集逻辑，仍强制关闭统计

**范围约束：** 只用 juya-miniapp-test；沿用协议勾选授权；保持本地 test 热更新；不上传、不部署、不更改生产配置
