# OSS资源自动发布实施计划

**Goal:** 用户已选定测试打包同步测试桶、生产正式release同步生产资源；普通生产构建、build-only、dry-run、开发及自动测试无外部上传

**Architecture:** Node脚本收集resources/oss内容哈希资源，先读取目标对象并比对字节，缺失才禁止覆盖创建；生产另通过现有SSH信任与静态服务镜像发布，最后验证公网GET。仅发布流程调用，失败阻断微信上传，资源重试幂等

**Tech Stack:** Node22、ali-oss、ssh2、Vitest；私有配置不带VITE前缀且被Git忽略

- [x] 隔离夹具测试新增、跳过、冲突、并发409、损坏公网响应、环境分离、路径/符号链接及哈希错误
- [x] 记录历史非哈希文件为固定归档，新增资源须内容哈希命名；JSON/MD不上传；同路径变内容禁止覆盖

## Task 2: 环境适配器

- [x] 生产SSH校验已信任主机指纹，原子同步新增文件及精确只读长期缓存路径，配置检查与失败回滚；不删除旧对象、不改变桶策略/ACL
