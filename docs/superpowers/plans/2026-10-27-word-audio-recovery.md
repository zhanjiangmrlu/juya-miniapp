# 词汇发音恢复与弱网优化

用户批准的实施边界：重点词汇和查词弹窗共用发音服务；逐次联网验权；整篇音频保持现状；不增加服务端接口、离线权限或长期缓存。

1. 为测试构建保留脱敏分段耗时与错误码，补充原生错误透传、旧音源事件隔离和错误分类测试。
2. 为词汇准备服务增加前台优先、500ms 下载等待上限及取消边界；下载文件保持真实 MP3/WAV 后缀；权限失败不能回退播放。
3. 点击立即加载，验权与音频准备并行，允许后才播放；临时失败最多恢复两次（250ms、750ms），本地文件失败最多重新下载一次且占用统一恢复预算；切词和离页取消。
4. 全套测试、静态检查、测试微信构建；独立代码审查；记录 iPhone / Android 真机尚未取得的证据，不能宣称截图问题已在手机解决。

默认在用户刚切换的本地主目录 test 分支实施，不推送、不部署。当前测试体验包对应的已知远端提交与本地在本次涉及的音频代码上无差异。
