# 友盟手动许可统计恢复

2026-11-15，用户授权在现有 test 分支修改和验证，并选择“恢复基础统计＋五类业务事件”。

## 目标和范围

沿用锁定的 umtrack-wx 2.8.0、隔离微信端口、可信账号许可及逐事件后端校验。用户手动允许新版说明后初始化 SDK，基础访问/活跃/会话/页面统计及 page_enter、content_open、audio_play、favorite_change、learning_complete 生效。关闭立即停止本设备后续发送、取消请求/计时器并丢弃队列；离线保持关闭；未许可期间不补报。

## 方案

选择恢复已有受控官方 SDK，避免新建第二条统计链路。仅五类手工事件不足以恢复用户截图中的基础报表；无门禁直接导入 SDK 会绕过撤回控制，均不采用。保留默认关闭、登录后独立选择、当前版本确认及账号隔离。基础设备/网络/随机标识和自动会话必须如实披露；不启用 OpenID、用户资料、剪切板或自动分享采集。

## 实现边界

小程序仅 test 微信构建在私有测试 AppKey 有效时装载 SDK；production、development、H5及分享模式继续关闭。API仅测试环境显式开启配置且发布本轮新版文档时提供真实客户端授权。新增版本化统计和隐私说明，旧许可失效，必要用户协议沿用。前端说明随实际能力显示就绪或未运行，不能承诺友盟已收妥。

本轮不推送、不部署远程、不上传微信包、不改生产或原业务库。真实友盟控制台入库需实际测试设备验证，不把隔离端口捕获当作服务端接收。
