## 统筹问题已关闭

入口复查发现首页和目录的旧响应能覆盖新请求或清空后缓存。6048bf5 为共享 store 增加请求代次及页面身份；取消、清空、旧成功、旧失败和 finally 均不能覆盖新请求。首页身份建立期间离页也会失效；取消旧首页不会取消学习页的新目录。首页、学习与探索的隐藏、退出生命周期已接入。新增 8 项回归，先复现失败再修复。

场景复查发现本地静音音频不支持 HTTP Range，第五句在浏览器中从零秒播放。小程序 API 876c75c 改用稳定 WAV 文件及 FileResponse，两个开发资源端点支持 GET/HEAD、206 部分内容、后缀范围与 416 越界。正式 API 路径及 OSS 签名逻辑未改。新增两个参数化测试，覆盖完整响应、首段、中段、后缀、越界及 HEAD；修改前失败，修改后通过。
