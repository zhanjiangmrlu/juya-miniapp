## 验收边界

实际浏览器到 HTTP 服务可以证明传输、CORS、客户端契约和开发页面交互。local_dev 服务使用内存样本，不能证明正式数据库、管理员发布、微信真实身份、OSS、正式音频、真机麦克风、生产或七天注销任务已验收。模拟设备、静音资源和本地开发身份需如实标明；对实际未验证环境保持待验收

实际样本不覆盖的权限/时间状态保持单独边界：FORMAL/PENDING、自动首次与收藏任务、限时权益待开始/激活，以及反馈补充/重开。本地上传 receiver 接收后丢弃文件，直传 204 和对象键读取不证明 OSS 对象内容或持久化。每组续交接逐项记录，不能把设计状态完整和已有自动测试等同为这些实际环境链路全部通过
