# 使用情况统计与第三方 SDK 披露

以下内容供句芽微信小程序隐私说明及第三方 SDK 清单使用；实际启用前须发布到产品采用的隐私说明位置，并同步微信公众平台隐私配置。

## 使用情况统计说明

在您选择同意后，句芽使用友盟小程序统计了解访问来源、页面浏览、功能使用及学习转化，以改进产品。您可选择暂不开启并继续使用现有功能，也可在「我的学习档案 → 数据与账号 → 使用情况统计」随时关闭。

统计处理随机统计标识、设备和平台基础信息（例如设备型号、品牌、系统及微信版本、语言、屏幕参数）、网络类型、入口场景、来源小程序标识、页面浏览及功能使用事件。网络请求接收方可获得连接 IP。具体采集以锁定 SDK 的实际行为及体验版核验为准。

本版本不向友盟提供微信号、手机号、OpenID、UnionID、句芽账号标识、昵称、头像、联系资料、反馈正文、截图、学习录音、登录令牌或带签名的素材地址。不自动获取或上传用户资料，不提供微信 AppSecret。

关闭后立即停止本次实例的新采集和请求，清理本机统计缓存。已经发送到统计服务的数据不会通过本地开关自动删除；相关个人信息处理及权利请求方式请参见友盟政策及产品隐私说明中的联系渠道。
