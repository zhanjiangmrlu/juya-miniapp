## 公共基础与接口

- 统一米色背景、绿色卡片、底栏原始 SVG、导航、按钮、弹层与播放控件；导航读取微信胶囊和状态栏，底部避让真实安全区，平板内容居中重排
- PublishedScene 与 PreviewScene 使用独立传输契约；预览只保留安全摘要，不能转换为完整正文。发布响应保留修订、内容版本、原图、整段音频、句子区间和词条版本
- 词卡、收藏和资源请求绑定 sceneId、revision_id、entry_version、来源定位；关闭词卡保持真实内部滚动位置
- 场景版本和整段音频在阅读、逐句跟读之间保持一致；整段、区间、词条发音和录音回听互斥，切换取消旧事件与异步签名
- 联系提示由服务端当前条件判定，对同用户跨幂等键只记一次曝光；当前页渲染前或离页迟到响应不能记录曝光
- 内部权益、目录安全摘要、反馈分页与补充截图补齐；活动成果按固定 scene_ids、激活/结束窗口统计，学习天数按实际事件的北京时间去重
- 联系自愿授权、收藏多来源、完整翻卡队列、反馈补充/一次重开、数据清空、注销摘要与撤回保持正式路径和鉴权规则兼容
- 本地 API 与 mock 响应同步更新。真实接口构建移除演示静音及大图，素材原件保留；微信开发验证产物最终约 459 KiB（470282 字节），避免将 9.5 MB 开发素材纳入真实接口包

## 微信开发者工具

实际运行微信开发者工具 2.02.2608040，SDK 3.17.2，iPhone 12/13 Pro 模拟器，390×844、状态栏 47px、底部安全区 34px。使用官方 CLI 的本地自动化入口与 miniprogram-automator；SDK 旧版查询返回结构由验收脚本适配，不修改应用代码。

已实际验证整段播放/暂停、词卡开关、进入跟读、第一句播放、切换第二句、暂停后继续、区间自然结束，以及原图、学习、探索、收藏、档案、权益、消息、反馈和账号页面导航。逐句检查记录的标签依次为“暂停”“暂停”“继续”“播放”；最终导航检查无脚本异常。最终 71 个 WXSS 文件通过微信工具内置编译器检查。

工具复查发现并修正两项浏览器未暴露的问题：微信 WXSS 不接受原居中选择器，改为普通类；微信运行时没有 crypto，旧进度队列导致逐句播放前保存位置抛错，改为现有兼容请求 ID。另按实际导航和安全区缩短对话滚动区，进入跟读按钮完整露出。

工具使用本地开发 API 与静音音频；自动化登录使用本地提供者 fixture，不代表真实微信服务器兑换和生产登录验收。本地工具允许访问 loopback，设置仅写在独立、忽略的验收产物目录。
